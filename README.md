# Hireling

Hireling is an addon manager for The Elder Scrolls Online, for Windows and Mac.
It installs and updates addons from ESOUI, keeps the libraries they need, lets
you roll an update back, and can sync your addon settings between PCs.

This repo only holds the downloads. Grab the newest one from
[Releases](../../releases/latest): the `-setup.exe` for Windows, the `.dmg` for
Mac. Once it's installed, Hireling updates itself.

Found a bug or want something added? You can send it from inside the app
("Send feedback or report a bug" at the bottom of the sidebar), or [open an issue](../../issues/new) here.

Hireling isn't made by or affiliated with ZeniMax Online Studios or ESOUI.
